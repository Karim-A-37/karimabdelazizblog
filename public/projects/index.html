Wazuh SIEM & XDR Labs

About This Project Wazuh is an open-source SIEM (Security Information and Event Management) and XDR (Extended Detection and Response) platform providing unified security monitoring across endpoints, networks, and cloud environments. This series documents three progressive labs built on Wazuh: Lab Focus Lab 1 Network IDS with Suricata — port scans, web attacks, Tor detection Lab 2 Malware detection — FIM, CDB hash lists, VirusTotal, Sysmon, fileless malware Lab 3 SetChain — Graduation project: 5-layer AI pipeline + IPFS + Hyperledger Fabric All labs were built in a VMware environment using Ubuntu, Rocky Linux, Kali Linux, and Windows 10 VMs. ...
